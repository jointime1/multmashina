# Рабочий процесс: команды и типичные поломки

Во всех примерах `$MM` — путь к `mm.sh` рядом со `SKILL.md` (см. начало SKILL.md). Команды запускаются из папки проекта человека: `build/`, `out/` и `review/` появятся в ней.

## Команды

| Команда | Что делает | Когда |
|---|---|---|
| `окружение` | проверяет ffmpeg, Chromium, uv и какие голоса доступны, советует бэкенд | в самом начале |
| `новый reels/имя --стиль dark-yard --название "…"` | создаёт эпизод из шаблона: 3 бита, герой, комната, субтитры | после согласованного сценария |
| `озвучить reels/имя [--голос edge] [--только hook,outro]` | озвучивает биты, выравнивает слова Whisper-ом, пишет `audio/*.mp3` и `audio/timings.json` | после правки `narration.yaml` |
| `проверить reels/имя [--строго]` | ошибки в сценах, слова вне безопасной зоны, длины, темп | после любой правки `scenes.js` |
| `кадры reels/имя [--моменты hook:0.3,offer:end]` | листы кадров `review/имя/лист-N.png` и `список.txt` | перед тем, как показывать человеку |
| `смотреть reels/имя` | предпросмотр в браузере со звуком (человеку; вы звук не слышите) | если человек хочет посмотреть до рендера |
| `снять reels/имя [--стиль light-cartoon] [--fps 30] [--потоков 4]` | MP4 1080×1920 и `.srt` в `out/` | в самом конце |
| `собрать reels/имя` | автономная страница в `build/` | отдельно почти не нужна |

## Экстры голоса

`озвучить` требует Python-пакеты, которые ставятся по выбору. Передайте `+voice` (выравнивание слов, всегда) и ровно один из `+qwen` | `+edge` | `+chatterbox`:

```bash
$MM +voice +edge озвучить reels/имя
```

`qwen` и `chatterbox` конфликтуют по версии библиотек: за один запуск выбирайте один. Если пакета не хватает, команда напишет, чем её запускать (в подсказках `uv run --extra …` — то же, что `+…` у `mm.sh`). Первый запуск `qwen` качает модели (≈4–9 ГБ) и идёт долго: предупредите человека заранее.

## Выбор голоса

1. `окружение` называет доступные бэкенды и рекомендует один.
2. Mac с Apple Silicon: `qwen-дизайн` (голос по описанию) → `qwen-клон` (один тембр на весь эпизод). Без Mac или без желания ждать: `edge` (нужен интернет). Подробности — `$MM_HOME/docs/voice.md`.
3. Подбор голоса на `qwen-дизайн`: озвучьте один-два бита (`--только hook`), отдайте человеку послушать, поправьте описание. Понравившуюся запись положите как `voice/ref.wav`, впишите её дословный текст в `текст_эталона`, переключите `бэкенд: qwen-клон`.
4. Звука вы не слышите. Не пишите «голос звучит отлично»; пишите «записал, длительность X с, темп Y слов/с, послушайте».

## Правка готового эпизода

| Что поменялось | Что перезапустить |
|---|---|
| только `scenes.js`, `props.js` | `проверить`, потом `кадры`; озвучивать заново не нужно |
| текст реплики в `narration.yaml` | `озвучить --только <биты>`, затем `проверить`, `кадры` |
| метки `[[…]]` в тексте | `озвучить --только <биты>` (тайминги слов меняются) |
| стиль, герой, комната | `проверить`, `кадры` |
| голос или темп | `озвучить` целиком: тембр должен быть общим на все биты |

Сырые записи лежат в `audio/raw/` и не пересоздаются, пока не изменился текст или настройки: исправить один бит дёшево.

## Типичные поломки

| Симптом | Причина | Что делать |
|---|---|---|
| `Нет героя «имя» в стиле` | герой используется в `scenes.js`, но не описан | добавьте его в `episode.yaml → герои` (или выберите из перечисленных в сообщении) |
| `Нет комнаты «имя» в стиле` | комнаты нет ни в стиле, ни в эпизоде | добавьте в `episode.yaml → комнаты` или используйте имя из списка в сообщении |
| опечатка в ключе YAML | ключи русские, неизвестный ключ — ошибка с подсказкой | поправьте ключ по сообщению |
| `В бите «…» нет метки «…»` | `m('метка')` в сцене, а в тексте бита её нет (или она в другом бите) | метки привязаны к биту: сверьте `narration.yaml`, потом `озвучить --только <бит>` |
| слово появилось раньше или позже, чем звучит | Whisper услышал слово иначе (имена, англицизмы) | пересоздайте бит (`озвучить --только …`) или перепишите слово в тексте так, как оно произносится |
| `страница не загрузилась` | ошибка в `scenes.js` при старте | в выводе `проверить` будет её текст |
| Whisper/модель качается долго | первый запуск | подождать; сообщить человеку |
| `ffmpeg: not found` / нет Chromium | окружение не готово | `cd $MM_HOME && uv run python -m playwright install chromium`; `brew install ffmpeg` |
| `no such file or directory: uv run …` | команда лежит в переменной и запущена в zsh | вызывайте через `mm.sh` (см. начало SKILL.md) |
| субтитры плохо читаются на этом фоне | настройки стиля | `docs/styles.md → Стиль` (раздел про субтитры) |
| рендер долго идёт | много браузеров на слабой машине | `--потоков 2`, если рядом работает что-то тяжёлое |

## Что отдать человеку

- Путь к `out/имя.mp4` и `out/имя.srt`.
- Длительность и количество битов.
- Что проверили (`проверить` чистая, листы просмотрены после последней правки) и что нет (звук на слух, вид в соцсети).
- Допущения, которые вы сделали за человека (стиль, голос, имена героев), чтобы он мог их поправить.
- Если текст содержит вымышленные цифры или реальные бренды, напомните про пометку на экране и про отметку синтетического голоса при загрузке в соцсеть.

# Озвучка

Команда `озвучить` делает для каждого бита: сырую запись выбранным бэкендом → ускорение и сжатие пауз → выравнивание громкости (−14 LUFS) → mp3 → времена слов (локальный Whisper) → `audio/timings.json`. Сырые записи лежат в `audio/raw/` и не пересоздаются, пока не изменились текст или настройки, поэтому исправить один бит дёшево.

Настройки — в `episode.yaml → озвучка`:

| Ключ | Для чего | Пример |
|---|---|---|
| `бэкенд` | `qwen-клон`, `qwen-дизайн`, `chatterbox`, `edge` | `qwen-клон` |
| `эталон`, `текст_эталона` | запись и её дословный текст для клона | `voice/ref.wav` |
| `описание` | описание голоса для `qwen-дизайн` (лучше по-английски) | см. пример |
| `темп` | ускорение записи без смены высоты | `1.3` |
| `seed` | число, фиксирующее случайность | `11` |
| `голос`, `скорость` | голос и темп Edge | `ru-RU-SvetlanaNeural`, `+16%` |
| `выразительность`, `cfg` | Chatterbox | `0.75`, `0.3` |
| `whisper` | модель выравнивания (`small` по умолчанию) | `small` |
| `громкость` | целевая громкость, LUFS | `-14` |

## Как получить голос под персонажа

1. Поставьте `бэкенд: qwen-дизайн` и опишите голос в `описание`. Озвучьте пару реплик, послушайте.
2. Подбирайте описание, пока тембр не устроит. Каждая реплика получает новый голос, поэтому целый эпизод так не озвучивают.
3. Понравившуюся запись положите как `voice/ref.wav`, впишите её дословный текст в `текст_эталона`, переключитесь на `qwen-клон`. Теперь все биты звучат одним голосом.
4. Либо запишите 10–15 секунд своего голоса (чистая речь без шума) и сразу используйте как эталон.

## Несколько голосов: герои говорят сами

Если в ролике говорят разные люди, опишите голоса в `озвучка → голоса` и пишите бит списком реплик `- голос: текст`:

```yaml
# episode.yaml (или общий серия.yaml)
озвучка:
  бэкенд: qwen-клон
  по_умолчанию: рассказчик          # голос для битов, написанных просто строкой
  голоса:
    рассказчик: {эталон: voice/рассказчик.wav, текст_эталона: "…"}
    олег:       {эталон: voice/олег.wav, текст_эталона: "…"}
```

```yaml
# narration.yaml
биты:
  спор:
    - олег: "[[a]]Ты не читал дифф!"
    - камиль: "Тесты были зелёные."
```

В одном бите можно мешать голоса: реплики озвучиваются по отдельности, громкость каждой выравнивается по речи, между ними вставляется короткая пауза, а метки и субтитры считаются по склеенному звуку. Изменилась одна реплика — заново озвучивается только она. Настройки голоса (`эталон`, `текст_эталона`, `seed`, `голос` и т. д.) перекрывают общие настройки озвучки. Модель Qwen при этом загружается один раз на все голоса.

## Образцы голоса по описанию

Команда `образец` делает несколько вариантов голоса по описанию (Qwen3-TTS VoiceDesign), чтобы выбрать тембр для клона:

```bash
mm.sh +voice +qwen образец voices/олег --seeds 1,2,3 \
  --описание "A Russian man in his mid 20s with a smooth, calm baritone voice, cold and noble" \
  --текст "Я видел, как рушатся королевства. Я видел, как падают сервера…"
```

Каждый seed даёт свой голос в заданном характере, рядом печатаются длительность и средняя высота тона. Эталон должен звучать 10–20 секунд; впишите его дословный `--текст` как `текст_эталона`. **Описание управляет и громкостью:** слова «aggressive, boisterous» дали крик вместо баса (≈300 Гц), а «very deep, slow, never shouting» — 105 Гц. Если нужен низкий голос, прямо пишите «very low pitch, slow, calm, never shouting» и без восклицательных знаков в тексте. Высота ≠ характер: тембр и манеру оценивает только слух, не пишите «голос получился», пока человек не послушал.

## Ловушка: текст эталона в кавычках

В YAML внутри `{…}` запятая обрывает значение: `текст_эталона: Триста сорок семь, блядь.` превращается в «Триста сорок семь», а клон получает эталон и обрубленный текст, после чего «заикается» (0,1 секунды вместо двух слов или минута болтовни). Всегда берите `текст_эталона` в кавычки. Движок сверяет длину записи и число слов в тексте и останавливается с понятным сообщением, если они не сходятся.

Каждая реплика озвучивается до 8 раз с разными seed и принимается, только когда длина нормальная, хвост не оборван, а Whisper разобрал почти все слова; в логе видно причину каждого брака (`брак: … с/слово, хвост …, распознано …%`).

## Метки и слова

В тексте перед словом ставится `[[имя]]`. После озвучки Whisper находит время слова, и `m('имя')` в сцене даёт его. Если слово Whisper услышал иначе (имена, англицизмы), время ставится между соседними словами: проверьте на слух, сдвинув картинку на кадр-другой при необходимости. Если слово произносится не так, как пишется (например, «сиИО» вместо CEO), покажите нужное написание в субтитрах через `субтитры → замены`.

## Память

Нейросеть озвучки — самый тяжёлый шаг. По умолчанию берётся **8-битная** Qwen3-TTS (≈ вдвое меньше памяти, чем bf16; нужно ≈ 4–5 ГБ); полную точность или другую модель можно указать в `озвучка → модель` (например `mlx-community/Qwen3-TTS-12Hz-1.7B-Base-bf16`). Перед загрузкой модели команда смотрит, сколько памяти доступно **без свопа** (свободная + файловый кэш; память, занятая виртуальными машинами вроде Docker, не считается свободной), и останавливается с понятным сообщением, а не вешает компьютер. Обойти проверку: `MM_IGNORE_MEMORY=1` (на свой страх). Для длины записи стоит потолок на слово, поэтому сбившаяся модель не «говорит» минуту и не раздувает память; такие обрывки и бесконечные записи перезаписываются с другим seed. Рендер видео сам уменьшает число одновременных браузеров, если памяти мало.

Если на машине работает Docker (его виртуальная машина занимает 10–20 ГБ), озвучивайте по одному эпизоду за раз и не запускайте параллельно рендер, тесты и другие тяжёлые задачи.

## Ограничения

- `qwen-*` работает только на Mac с Apple Silicon (mlx-audio), `chatterbox` — PyTorch (mps или cpu), `edge` требует интернет.
- Qwen и Chatterbox ставятся в разные окружения: у них несовместимые версии `transformers`.
- В записи Chatterbox вшит неслышимый водяной знак Resemble AI (Perth).
- Звук нужно слушать самому: числа показывают высоту и громкость, но не «пропитость» и не акцент.

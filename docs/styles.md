# Справочник по стилям и эпизодам (YAML)

Ключи русские, цвета — `"#rrggbb"` в кавычках. Любой раздел можно не указывать: подставится значение по умолчанию. Опечатка в ключе даёт понятную ошибку со списком допустимых.

## Стиль (`styles/<имя>.yaml`)

```yaml
название: Тёмный двор
сцена:    {ширина: 900, высота: 1600}
палитра:  {тёмный, светлый, красный, акцент, приглушённый, маркер, зелёный, контур, глубина, сталь}
шрифты:   {заголовки, запасные, моно, подгрузить, файлы}
субтитры: {y, размер, цвет, обводка, слов, знаков, пауза, ширина}
эффекты:  {зерно, виньетка, опережение, пауза_после_бита}
анимации: {характер, входы, переходы, камера, амплитуда_камеры, длина_перехода, реакция}
манера:   {персонаж, пиксели, линия, дрожь, мелкость, смена_дрожи, рывки, тона, ступени, растр, бумага, плоско, глаза, ширина_головы, высота_головы, тело, шея, комнаты_стиля}
офис:     {стена, низ_стены, потолок, пол, низ_пола, окно_верх, окно_низ, здания}
комнаты:  {<имя>: {стена, низ_стены, пол, низ_пола, горизонт, лампа_x, свет, трубы, узор, вывеска, цвет_вывески, вывеска_x, вывеска_y, размер_вывески}}
```

- `шрифты → файлы` — css-файлы с `@font-face` (лежат в `fonts/`; в комплекте Oswald с кириллицей). Свой шрифт: положите файлы и css в `fonts/`, укажите семейство в `заголовки`.
- `субтитры → y` — высота; ниже 1300 кадр закрывают кнопки платформы.
- `эффекты → опережение` — на сколько секунд картинка опережает слово; `зерно` — `true/false`; `виньетка` — сила от 0 до 1; `пауза_после_бита` — тишина после голоса до следующей сцены (по умолчанию 0,3 с; на видео пауза = эта + хвост голоса, дольше 0,6 с ощущается провалом).
- `анимации` — разнообразие движения, всё по кругу и без случайности (кадр по-прежнему функция времени). Раздела нет или списки пустые — поведение как раньше. Списки в `[скобках]`:
  - `входы` — как появляются слова, ярлыки и иконки: `всплытие`, `падение`, `слева`, `справа`, `подъём`, `зум`, `вращение`; соседние надписи берут разные;
  - `переходы` — между сценами (первая сцена без перехода): `рывок` и `сдвиг` двигают обе сцены, `зум` — с перекрёстным затуханием, `вспышка`, `затемнение`, `склейка` (без перехода). Вставьте `склейка` в список, чтобы ритм не был суетливым;
  - `камера` — медленное движение плана на каждой сцене: `наезд`, `отъезд`, `вправо`, `влево`, `стоп`; субтитры стоят на месте. `амплитуда_камеры` — доля масштаба (0,04 = 4 %; подбородок героя при наезде сползает к субтитрам, для плотных кадров 0,03);
  - `длина_перехода` — секунды (0,22); `реакция` — сила «вздрагивания» героя при смене эмоции (0,05; 0 — выключить);
  - `характер` — как движется всё в ролике: `плавный` (по умолчанию), `пружина`, `резкий`, `механика` (см. «Школа анимации»).
  В третьем элементе бита можно задать своё: `{ trans: 'flash', cam: 'in' }`, у слова — `{ enter: 'drop' }`, см. [scenes.md](scenes.md).
- `комнаты → узор` — число, от которого зависит рисунок облупившейся стены (разные числа — разные стены). `низ_пола` — цвет, к которому темнеет пол у нижнего края кадра (`офис` и `комнаты`).
- `офис` красит не только офис, но и все готовые локации: `street`, `kitchen`, `metro`, `meeting`, `stairs` (`docs/scenes.md`, раздел «Декорации»).

## Школа анимации

Ролики бывают разными не только цветом. У стиля есть школа: из чего собран персонаж, как он двигается и как идёт монтаж. Одну и ту же сцену и ту же озвучку разные школы разыгрывают по-разному: руки, рот, веки, пружина, ступени. Школа складывается из трёх ключей: `манера → персонаж`, `анимации → характер` и обычных `анимации → входы / переходы / камера`.

**Персонаж** (`манера → персонаж`) — устройство героя. Герои те же (цвета, очки, усы, доспех из раздела `герои`), эмоции те же (`shock`, `cry`, `rage`…), вызовы те же (`hero`, `closeUp`, `figure`…). Меняются рисунок и то, как герой играет эмоцию:

| Персонаж | Из чего собран | Как играет |
|---|---|---|
| `обычный` | голова с очками, толстовка, глаза с белками, рот из кривых | лицо гнётся плавно, голова подпрыгивает на смене эмоции; рук нет |
| `каракуля` | линия, голова-кружок, глаза-точки; человечек целиком — палочки | **руки играют**: вскидывает при шоке, закрывает лицо при плаче, трясёт кулаками в ярости, ладонь к подбородку при раздумье |
| `марионетка` | бумажные детали на шарнирах с тенью; форма детали не меняется | **подмена, не изгиб**: рот — один из шести готовых, веко — одно из четырёх положений, поворот и сдвиг ступенями; руки-картонки; кукла ходит, раскачиваясь, ноги не гнутся |
| `желе` | колобок: голова и тело — один пружинящий комок | **пружина**: после каждой реакции тело вытягивается, сплющивается и качается, затухая; колышется в покое; толстые ручки запаздывают; человечек ходит прыжками |
| `силуэт` | театр теней: сплошная фигура одного глубокого цвета героя с яркой контровой каймой, глаза, рот, брови и очки светятся тем же оттенком | **поза**: качается на палочке, руки-палки вскидываются и закрывают лицо, глаза косеют от злости; оттенок берётся у героя (цвет глаз, одежды или кожи), у разных героев разный |
| `шланг` | резиновый шланг 1930-х: глаза с вырезом «пирог», руки-макароны, белые перчатки, пуговицы | **такт**: подпрыгивает с приседанием 2,4 раза в секунду даже молча, макароны всё время колышутся; чем сильнее реакция, тем выше прыжок и шире махи |
| `пиксель` | герой из квадратов сетки 20 × 20 (спрайты в ascii), ничего не повёрнуто и не растянуто | **подмена по клеткам**: рот, веко, брови и поза рук — готовые спрайты; сдвиги только на целую клетку; дышит шагом каждые 0,4 с |

Облик из стиля читается не весь. У новых персонажей рисуются: цвет кожи и волос, очки, усы, лысина, длинные волосы, кепка (`rank`), цвет одежды, доспех с шипами, плащ, галстук, комплекция, цвет глаз. Коробка, татуировки, сварочная маска и надпись на толстовке есть только у обычного героя. У силуэта усы и кожа не видны (всё залито одним цветом). Вид со спины и сверху (`backView`, `topView`) у всех персонажей одинаковый.

**Характер движения** (`анимации → характер`) — набор кривых на весь ролик. Один и тот же код сцены с пружиной «играет», а с механикой «едет по рельсам»:

| Характер | Кривые | Чувствуется как |
|---|---|---|
| `плавный` | как всегда | обычный мультик |
| `пружина` | всё, что «выпрыгивает» (вход героя, вращение), раскачивается 3–4 раза вокруг цели | резина, мармелад |
| `резкий` | почти мгновенно долетает и коротко садится | рисованная ручкой анимация, плакат |
| `механика` | линейно, без разгона и перелёта | бумажные куклы на палочках, лента печатной машины |

Числа и линии при любом характере не перелетают цель: счётчик не покажет 1 120 000 вместо 1 000 000.

**Монтаж** тоже часть школы: в `notebook` страницы не перелистывают плавно (склейки), в `jelly` сцены въезжают рывком и зумом, в `cutout` куклу ведут по столу линейно, в `shadow` сцены медленно ведут панорамой и гаснут в затемнение, в `pixel` меняются склейкой. Пример готовой пары: `jelly` против `cutout` на одной озвучке.

**Что взять под сюжет.** Спокойное и бытовое: `notebook`, `shadow`. Весёлое и безобидное: `jelly`, `hose`. Игра, технарский юмор: `pixel`. Конец света, лозунги: `poster`. Расследования: `newspaper`. Детская наивность и абсурд: `cutout`.

## Манера рисунка

Манера — это то, чем ролики отличаются на первый взгляд: линия, цвет, темп движения, форма лица. Раздел `манера` есть в стиле, а в `episode.yaml` или `серия.yaml` можно перекрыть отдельные ключи. В `dark-yard` и `light-cartoon` манеры нет: они рисуются как раньше.

| Стиль | Что это | Школа |
|---|---|---|
| `dark-yard` | тёмные помещения, неон, зерно | обычный, плавный |
| `light-cartoon` | яркий плоский мультик | обычный, плавный |
| `notebook` | цветные маркеры и ручка на листе в клетку | **каракуля**, резкий; дрожащая линия, рывки 8 в секунду, склейки |
| `poster` | яркий трафаретный плакат: фиолетовый, бирюзовый, оранжевый | обычный, резкий; жирный контур, рывки 12, вспышки |
| `newspaper` | цветной газетный комикс | обычный, механика; точечный растр поверх красок, рывки 10 |
| `cutout` | аппликация из цветной бумаги | **марионетка**, механика; без обводки, рваная кромка, рывки 6 |
| `jelly` | мармеладные цвета, толстый мягкий контур | **желе**, пружина; плавные 30 кадров, прыжки и зум |
| `shadow` | театр теней в цвете: закат, фигуры глубокого цвета героя с неоновой каймой | **силуэт**, плавный; медленные панорамы, затемнения |
| `hose` | цветная плёнка 1930-х с зерном | **шланг**, пружина; тёплая красочная палитра, дрожь плёнки, 12 кадров в секунду |
| `pixel` | игра в 16 бит: яркие чистые цвета | **пиксель**, резкий; склейка кадра в клетки, 8 кадров в секунду |

| Ключ | Что делает | Значения |
|---|---|---|
| `персонаж` | как построен и как играет герой | `обычный`, `каракуля`, `марионетка`, `желе`, `силуэт`, `шланг`, `пиксель` (см. «Школа анимации») |
| `пиксели` | склеить кадр в клетки (крупные точки): берётся цвет в центре клетки | 0 выключено; размер клетки в единицах сцены (900 × 1600). Кратные 5 дают целые пиксели в видео 1080 px (5 → 6 px, 10 → 12 px). Мельче клетка — читаются надписи, крупнее — мелкий текст расползается; субтитры лежат вне фильтра и остаются чёткими |
| `линия` | толщина тёмного контура | 1 как нарисовано, 0.7 тонкая, 1.8 жирная, 0 без обводки |
| `дрожь` | насколько плавает линия | 0 выключена, 1 едва заметно, 2.5 от руки; выше 6 не берите |
| `мелкость` | размер дрожи | 0.012 плавные волны, 0.03 неровная линия, 0.06 рваная кромка |
| `смена_дрожи` | сколько раз в секунду рисунок перерисовывается | 8; 3 для бумаги; 0 — линия кривая, но неподвижная |
| `рывки` | кадров анимации в секунду | 0 плавно, 12 как в рисованной анимации, 8 и 6 заметные рывки |
| `тона` | цвета кадра от тёмного к светлому | список от двух цветов; цвет выбирает яркость точки |
| `ступени` | тона ступенями или плавно | `true` чёткие границы (по умолчанию), `false` плавный переход |
| `растр` | размер ячейки точечного растра | 0 выключен, 12 газета; работает вместе с `тона` |
| `бумага` | линии бумаги поверх рисунка | `нет`, `клетка`, `линейка` |
| `плоско` | заливки без градиентов у декораций | `true` / `false` |
| `глаза` | форма глаз | `обычные`, `точки` |
| `ширина_головы`, `высота_головы` | форма головы | доли от обычной: 0.9 и 1.08 — вытянутая, 1.1 и 0.92 — приплюснутая |
| `тело` | ширина тела | 1 обычное, 0.7 узкое, 1.1 широкое |
| `шея` | длина шеи | 1 обычная, 1.3 длинная |
| `комнаты_стиля` | стены и пол комнат эпизода берутся у стиля | `true`, если серия с тёмными комнатами снимается в светлой манере |

Как собрать свою: скопируйте близкий файл из `styles/` и поменяйте `тона`, `линия` и `рывки`, они дают больше всего. Все готовые стили полноцветные, `тона` в них не используются (это проверяет тест); ключ остаётся для своих одноцветных стилей. Яркость решает, какой тон достанется точке: стена в средней яркости становится вторым цветом, поэтому в `poster` стены заданы серыми, а на экране они красные. Посмотрите результат командой `кадры`: у тонов бывают сюрпризы, тёмная одежда сливается с тёмным полом.

Цена кадра 1080×1920: без манеры 50 мс, с тонами 80 мс, с дрожью 160 мс. Дрожь берите вместе с `рывки`: при 12 снимается 12 кадров в секунду из 30, остальные копируются, и ролик снимается почти за то же время, что и без манеры. Точки растра и бумажная клетка утяжеляют файл видео.

## Герои и комнаты эпизода (`episode.yaml`)

Те же `комнаты`, плюс `герои`. Описанное в эпизоде добавляется к стилю и перекрывает одноимённое.

```yaml
герои:
  петя:
    кожа: "#f2c29b"
    волосы: "#3b2a20"
    очки: true
  охранник: {пиджак: "#1f2937", кепка: "#111827", без_красного_носа: true, очки: false}
```

Ключи героя: `кожа`, `волосы`, `очки`, `толстовка`, `пиджак`, `рубашка`, `галстук`, `лысый`, `длинные_волосы`, `помада`, `без_красного_носа`, `кепка`, `коробка`.

Для узнаваемых персонажей есть ещё:

| Ключ | Что делает |
|---|---|
| `доспех` | цвет стального доспеха: нагрудник, воротник, наплечники с шипами; `плащ` — цвет плаща сзади |
| `руки` | голые руки по бокам (майка вместо толстовки) |
| `тату` | цвет татуировок на руках и шее (рисуются на руках, поэтому с `руки`) |
| `комплекция` | ширина торса, шеи и рук: 1 обычная, 1,5 — качок |
| `усы`, `цвет_усов` | усы |
| `щетина_на_голове` | бритая голова со щетиной (вместе с `лысый: true`) |
| `глаза` | цвет радужки (светящиеся «ледяные» глаза: `"#38bdf8"`) |
| `брови` | цвет бровей, если отличается от волос |
| `надпись`, `цвет_надписи` | надпись на толстовке вместо `</>`: `Py`, `CODEX` |

## Серия: общий конфиг для нескольких частей

Когда у героев несколько эпизодов, общее выносится в отдельный файл, а в эпизоде остаётся одна строка:

```yaml
# часть1/episode.yaml
название: "Выжить в проде. Часть 1"
серия: ../серия.yaml
```

В `серия.yaml` лежит всё то же, что можно писать в `episode.yaml` (стиль, герои, комнаты, озвучка с голосами, замены в субтитрах, `скрипты: [../props.js, scenes.js]`). Разделы `эффекты`, `субтитры` и `анимации` эпизода или серии перекрывают стиль по ключам: например, `эффекты: {пауза_после_бита: 0.2}` для быстрого диалога. Значения эпизода перекрывают общие, словари сливаются по ключам. Пути к эталонам и скриптам считаются от папки эпизода.

## Остальное в `episode.yaml`

| Ключ | Что |
|---|---|
| `название` | название эпизода (заголовок страницы) |
| `стиль` | имя стиля из `styles/` или путь к `.yaml` |
| `скрипты` | файлы эпизода, подключаются после движка по порядку |
| `озвучка` | бэкенд и его настройки, см. [voice.md](voice.md) |
| `субтитры → замены` | как слово произносится → как показывать (`сиио: CEO`) |

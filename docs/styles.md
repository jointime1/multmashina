# Справочник по стилям и эпизодам (YAML)

Ключи русские, цвета — `"#rrggbb"` в кавычках. Любой раздел можно не указывать: подставится значение по умолчанию. Опечатка в ключе даёт понятную ошибку со списком допустимых.

## Стиль (`styles/<имя>.yaml`)

```yaml
название: Тёмный двор
сцена:    {ширина: 900, высота: 1600}
палитра:  {тёмный, светлый, красный, акцент, приглушённый, маркер, зелёный, контур, глубина, сталь}
шрифты:   {заголовки, запасные, моно, подгрузить, файлы}
субтитры: {y, размер, цвет, обводка, слов, знаков, пауза, ширина}
эффекты:  {зерно, виньетка, опережение, пауза_после_бита}
анимации: {входы, переходы, камера, амплитуда_камеры, длина_перехода, реакция}
офис:     {стена, низ_стены, потолок, пол, окно_верх, окно_низ, здания}
комнаты:  {<имя>: {стена, низ_стены, пол, горизонт, лампа_x, свет, трубы, узор, вывеска, цвет_вывески, вывеска_x, вывеска_y, размер_вывески}}
```

- `шрифты → файлы` — css-файлы с `@font-face` (лежат в `fonts/`; в комплекте Oswald с кириллицей). Свой шрифт: положите файлы и css в `fonts/`, укажите семейство в `заголовки`.
- `субтитры → y` — высота; ниже 1300 кадр закрывают кнопки платформы.
- `эффекты → опережение` — на сколько секунд картинка опережает слово; `зерно` — `true/false`; `виньетка` — сила от 0 до 1; `пауза_после_бита` — тишина после голоса до следующей сцены (по умолчанию 0,3 с; на видео пауза = эта + хвост голоса, дольше 0,6 с ощущается провалом).
- `анимации` — разнообразие движения, всё по кругу и без случайности (кадр по-прежнему функция времени). Раздела нет или списки пустые — поведение как раньше. Списки в `[скобках]`:
  - `входы` — как появляются слова, ярлыки и иконки: `всплытие`, `падение`, `слева`, `справа`, `подъём`, `зум`, `вращение`; соседние надписи берут разные;
  - `переходы` — между сценами (первая сцена без перехода): `рывок` и `сдвиг` двигают обе сцены, `зум` — с перекрёстным затуханием, `вспышка`, `затемнение`, `склейка` (без перехода). Вставьте `склейка` в список, чтобы ритм не был суетливым;
  - `камера` — медленное движение плана на каждой сцене: `наезд`, `отъезд`, `вправо`, `влево`, `стоп`; субтитры стоят на месте. `амплитуда_камеры` — доля масштаба (0,04 = 4 %; подбородок героя при наезде сползает к субтитрам, для плотных кадров 0,03);
  - `длина_перехода` — секунды (0,22); `реакция` — сила «вздрагивания» героя при смене эмоции (0,05; 0 — выключить).
  В третьем элементе бита можно задать своё: `{ trans: 'flash', cam: 'in' }`, у слова — `{ enter: 'drop' }`, см. [scenes.md](scenes.md).
- `комнаты → узор` — число, от которого зависит рисунок облупившейся стены (разные числа — разные стены).

## Герои и комнаты эпизода (`episode.yaml`)

Те же `комнаты`, плюс `герои`. Описанное в эпизоде добавляется к стилю и перекрывает одноимённое.

```yaml
герои:
  петя:
    кожа: "#f2c29b"
    волосы: "#3b2a20"
    очки: true
  охранник: {пиджак: "#1f2937", кепка: "#111827", без_красного_носа: true, очки: false}
```

Ключи героя: `кожа`, `волосы`, `очки`, `толстовка`, `пиджак`, `рубашка`, `галстук`, `лысый`, `длинные_волосы`, `помада`, `без_красного_носа`, `кепка`, `коробка`.

Для узнаваемых персонажей есть ещё:

| Ключ | Что делает |
|---|---|
| `доспех` | цвет стального доспеха: нагрудник, воротник, наплечники с шипами; `плащ` — цвет плаща сзади |
| `руки` | голые руки по бокам (майка вместо толстовки) |
| `тату` | цвет татуировок на руках и шее (рисуются на руках, поэтому с `руки`) |
| `комплекция` | ширина торса, шеи и рук: 1 обычная, 1,5 — качок |
| `усы`, `цвет_усов` | усы |
| `щетина_на_голове` | бритая голова со щетиной (вместе с `лысый: true`) |
| `глаза` | цвет радужки (светящиеся «ледяные» глаза: `"#38bdf8"`) |
| `брови` | цвет бровей, если отличается от волос |
| `надпись`, `цвет_надписи` | надпись на толстовке вместо `</>`: `Py`, `CODEX` |

## Серия: общий конфиг для нескольких частей

Когда у героев несколько эпизодов, общее выносится в отдельный файл, а в эпизоде остаётся одна строка:

```yaml
# часть1/episode.yaml
название: "Выжить в проде. Часть 1"
серия: ../серия.yaml
```

В `серия.yaml` лежит всё то же, что можно писать в `episode.yaml` (стиль, герои, комнаты, озвучка с голосами, замены в субтитрах, `скрипты: [../props.js, scenes.js]`). Разделы `эффекты`, `субтитры` и `анимации` эпизода или серии перекрывают стиль по ключам: например, `эффекты: {пауза_после_бита: 0.2}` для быстрого диалога. Значения эпизода перекрывают общие, словари сливаются по ключам. Пути к эталонам и скриптам считаются от папки эпизода.

## Остальное в `episode.yaml`

| Ключ | Что |
|---|---|
| `название` | название эпизода (заголовок страницы) |
| `стиль` | имя стиля из `styles/` или путь к `.yaml` |
| `скрипты` | файлы эпизода, подключаются после движка по порядку |
| `озвучка` | бэкенд и его настройки, см. [voice.md](voice.md) |
| `субтитры → замены` | как слово произносится → как показывать (`сиио: CEO`) |

# Мультмашина: инструкции для ИИ-агента

Мультмашина делает вертикальные мультики и рилсы: вы пишете сценарий, герои, сцены и текст, а инструмент озвучивает, рисует, проверяет и снимает MP4. Репозиторий на русском, и общаться с человеком нужно по-русски.

## Если просят сделать ролик

Читайте и выполняйте [.claude/skills/multmashina/SKILL.md](.claude/skills/multmashina/SKILL.md). Там весь порядок работы: знакомство, сценарий, `новый`, озвучка, сцены, `проверить`, `кадры`, `снять`. Справочники лежат рядом (`references/`) и в `docs/`.

Команды запускаются обёрткой `.claude/skills/multmashina/mm.sh` из любой папки (в zsh переменная вида `MM="uv run …"` не работает: она не разбивается на слова):

```bash
MM=.claude/skills/multmashina/mm.sh
$MM окружение                            # что есть на машине
$MM +voice +edge озвучить reels/ролик    # экстры озвучки: ведущие +имя
```

Если скилл подключён без клона репозитория, `setup.sh` рядом с `SKILL.md` печатает путь к рабочей копии (клонирует при необходимости).

## Правила для агента

- **Смотрите свою работу.** После правки сцен запускайте `проверить`, затем `кадры` и открывайте листы как картинки. Рендер без просмотра кадров не считается готовой работой.
- **Звука вы не слышите.** Не пишите «голос получился отличным». Передайте человеку, что и где послушать.
- **Факты берите у человека.** Цифры, бренды и истории, которых он не давал, не выдумывайте как факты. Вымысел помечайте на экране.
- **Мат и жёсткий юмор** — только если об этом просили.
- **Не клонируйте чужие голоса.** Эталон для клона — своя запись человека или синтетический голос.
- **Не публикуйте и не отправляйте** ролики и репозиторий без явной просьбы.

## Если вы правите сам репозиторий

- Движок: `engine/*.js` (чистый JS без сборки, каждый кадр — функция от времени), оркестрация: `scripts/mm.py` и `scripts/mmlib/`.
- Конфиги YAML с русскими ключами; сообщения об ошибках, документация и тесты — по-русски. Идентификаторы в коде и файлах, которые читают другие программы (имена битов), — латиницей.
- Герои и комнаты описываются в `episode.yaml`, а не в стиле: иначе смена стиля ломает эпизод.
- Служебная команда `ассеты` перегенерирует звуковые эффекты и зерно (`assets/`); обычному ролику она не нужна.
- Тесты: `uv run --extra dev python -m pytest` (часть тестов запускает Chromium, нужен `python -m playwright install chromium`).
- Проверка скилла: `tests/test_skill.py` следит, чтобы ссылки в `SKILL.md` вели в существующие файлы, а все команды `mm.py` были описаны.
- Новые облики героев и эмоции добавляются в `engine/characters.js`, новые способы построить героя целиком (персонажи) — в `engine/rigs.js`; опишите их в `docs/scenes.md` и `docs/styles.md`.
